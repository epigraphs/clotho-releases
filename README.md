# Clotho

A standalone Windows client for [Agar.io](https://agar.io) with built-in
[Raga](https://minions.raga.pw) Mode. No browser needed.

## Download

Get the latest version from [Releases](https://github.com/epigraphs/clotho-releases/releases/latest):

- **`Clotho_x.y.z_x64-setup.exe`**: the installer (recommended). It updates itself automatically.
- **`Clotho_x.y.z_x64_portable.exe`**: a single exe with no install and no auto-update.

Requires Windows 10 or 11. The installer downloads Microsoft's WebView2 runtime if it's missing.
Windows 11 already includes it.

## Features

- Raga Mode is installed on first launch and kept up to date. No extension is needed.
- Unlocked FPS, and no slowdown when the game is in the background.
- Ad and tracker blocking.
- F11 fullscreen, F5 reload.
- Discord Rich Presence.
- Settings live in the tray icon.

## Notes

Clotho loads the official agar.io site. Raga Mode is downloaded from Raga's own server at
runtime. Clotho isn't affiliated with Miniclip or Raga. Using bots may break Agar.io's terms of
service, at your own risk.

This repository only hosts release builds.
